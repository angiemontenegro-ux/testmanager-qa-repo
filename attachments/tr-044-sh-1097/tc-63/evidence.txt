SC 2  "the Item selector only offers items belonging to the selected Categories"
VERDICT: PASSED
ShopRuleCardPreview.tsx:229-240:
  /** Item options cascade from the chosen Category (rule-cards spec, "Item
      options cascade from the chosen category"); `All Items` is always offered. */
  export function computeShopItemOptions(categoryId, itemOptions) {
      if (categoryId === null || categoryId === ALL_CATEGORIES_ID) { ...all... }
      return itemOptions.filter((item) => item.categoryId === categoryId);
  }
Cited to the spec, All Items pinned regardless, and covered by
ShopRuleCardPreview.test.tsx. This also settles the TC's framing note: scope IS
Category + Item with a cascade, not an "All items in categories vs Specific
items" toggle.
